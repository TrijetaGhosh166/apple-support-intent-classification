# AI Customer Support Agent

## Objective
Build an AI-powered customer support agent for Apple Support.

## Dataset
Customer Support on Twitter (Kaggle)

## Steps
- Data exploration
- Intent classification
- Sentence embeddings
- Similar conversation retrieval
- AI reply generation
- AI judge evaluation

## Model
- Logistic Regression
- all-MiniLM-L6-v2
- Gemini 3.6 Flash

## Accuracy
Intent Classification Accuracy: 72%

## How to Run

1. Install requirements
2. Run notebooks
3. Add Gemini API key
4. Execute AI agent
